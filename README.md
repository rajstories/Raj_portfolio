## 🎨 Features

This portfolio is built with a **dark-themed, glassmorphism-inspired design** featuring:

*   **Interactive Hero Section:** Mouse-tracking parallax effects with 3D elements.
*   **Dynamic Resume Generation:** Client-side PDF generation using `jsPDF` (converts HTML/Text to a structured A4 PDF instantly).
*   **Smooth Navigation:** Scroll-spy navigation with active state tracking.
*   **Project Showcase:** Detailed modal views for projects like *ThreatPilot* and *SAKSHAM*.
*   **Responsive Design:** Fully optimized for Mobile, Tablet, and Desktop.
*   **Content Integration:** A dedicated section bridging my technical work with my storytelling journey on Instagram.

## 💻 Local Development

To run this portfolio locally on your machine:

1.  **Clone the repository**
    ```bash
    git clone https://github.com/rajstories/portfolio.git
    ```

2.  **Navigate to the directory**
    ```bash
    cd portfolio
    ```

3.  **Install dependencies**
    ```bash
    npm install
    ```

4.  **Start the development server**
    ```bash
    npm run dev
    ```
